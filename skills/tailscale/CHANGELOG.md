# Changelog — tailscale

- 2026-07-26 — v1.1.0: gate work on tailnets the operator does not own, and surface `tailscale switch` as the network-switching mechanism it is → adds `Process` step 2 (classify own-vs-external ownership; explicit per-task approval required before any command that reaches or mutates a shared-in node or an invited tailnet, with read-only status/`switch --list`/`ping`/discovery-hops always permitted), renumbers the following steps, inserts §A1 `Ownership classification` into `references/tailnet-profile-and-identity-changes.md` with the `Self`-vs-peer `LoginName` comparison and the ambiguity-resolves-toward-asking rule, promotes ownership to the second check in that reference's decision order, states the multi-login/`tailscale switch` model in the preamble and `When to use`, and registers seven anti-patterns (reachable-implies-authorized, stored-login-implies-consent, approval carried across tasks, discovery hop used as a foothold, guessing at ambiguous ownership, host left parked on a hopped-into profile). Corrects the prior assumption that any peer visible in `tailscale status` was the operator's to dispatch against.

- 2026-07-18 — v1.0.0: port the tailnet-health-gate skill into this library so cross-host SSH/`scp` work can verify the tailnet before dispatch → seeds `SKILL.md` (network-vs-service triage, macOS daemon-variant restart paths, macsys → headless migration, OAuth-popup owner classification, profile/identity/reachability drift) with one `## Anti-patterns` registry and five `references/`, and folds in `tailscale switch <profile>` as a discovery tool for locating which tailnet owns a node missing from `tailscale status` before concluding the peer is offline. Provenance: derived from the `tailscale` skill (v1.1.1) in [bstack](https://github.com/GoBeromsu/bstack); frontmatter converted to this library's contract (`metadata.version`, dropped `allowed-tools`/`compatibility`) and `Red Flags` + `Common Rationalizations` merged into `## Anti-patterns`.
- 2026-08-28 — v1.2.0: mutable Tailscale CLI and daemon facts need runtime evidence handling → official-docs-first conflict disclosure, specific-evidence precedence, and safe stops without invented commands or capabilities.
