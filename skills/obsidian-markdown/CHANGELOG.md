# Changelog

- 2026-07-12 — v1.0.0: ported obsidian-markdown into craft-skills → Obsidian Flavored Markdown syntax reference plus a compact note house style (heading/indent/spacing/footnote rules); genericized personal-vault framing and dropped the vault-specific fleeting-note reference. Provenance: bstack obsidian-tools/obsidian-markdown.
- 2026-07-26 — v2.0.0: operator house-style corrections from a vault note-cleanup session → **breaking**: Rule 6 reverses the web-link default from markdown footnotes to inline `[label](url)`, so a caller already formatting notes against v1.x gets different output for the same source and the `web links as footnotes` phrase leaves the description. Adds Rule 7 (body dates as `[[YYYY-MM-DD]]`, YAML date scalars stay plain, and no inferring a year the source never stated) and Rule 8 (person names as `[[Name]]` on first mention, People-note creation explicitly out of scope). Rule 2 now prefers nested tab bullets when an item has genuine sub-context and states that co-attributes of one subject are siblings, not children; it also absorbs the YAML-spaces carve-out that had been stranded under the web-link rule. Verification exempts date and person wikilinks from the resolve-or-placeholder check, since both are placeholders by design. Examples use neutral placeholders only. The description is also rewritten against undertriggering: the trigger surface is now "any `.md` note that lives in an Obsidian vault", stated to apply even when the request never mentions Obsidian or its syntax, and the OFM-jargon trigger phrases are joined by ordinary ones — meeting note, journal entry, summary, captured idea, cleaning up an existing note. Provenance: operator correction during a note-formatting session.
- 2026-08-27 — v3.0.0: moved from GoBeromsu/craft-skills@ca9eb6c8 skills/obsidian-markdown, converted frontmatter to the bstack 5-key contract (name/description/version/allowed-tools/compatibility), and renamed to `obsidian/markdown` as part of the domain-topology reorganization.
- 2026-08-27 — v3.1.0: ported craft-skills obsidian-markdown v3.0.0's headings-first house-style correction (operator correction after a readability incident, craft-skills is now retired and bstack is SSOT) → headings now carry structure (`##` main / `###` topical / `####` sub-topic) instead of bullet nesting; bullets capped at depth 2 with one idea per line (no →/em-dash clause chains); 3+ comparable items become a table; sequences use numbered lists (bans `- 1.` double signaling); blank lines around headings/tables/blocks are now required, reversing the old "no blank lines in the body" rule; a plan, an artifact's structure, a reference checklist, and rationale may not share one bullet tree. Rules renumbered 1-11 to fit the new splits (old Rule 5 "preserve source text" is now Rule 8, old Rule 6 "inline web links" is now Rule 9, old Rule 7/8 date and person wikilinks are now Rule 10/11). Adds an Anti-pattern vs. Good example. Kept: no H1/H5+, hyphen+tab bullets, inline links, date/person wikilinks, all OFM syntax coverage. Provenance: GoBeromsu/craft-skills obsidian-markdown v3.0.0 (retired), original provenance operator correction during a note-formatting session.
- 2026-08-28 — v4.0.0: moved the active Obsidian markdown skill from GoBeromsu/bstack@3e0672c into craft-skills as `obsidian-markdown`, replacing the deprecated stub and restoring craft-skills as the reusable Obsidian-craft owner.
