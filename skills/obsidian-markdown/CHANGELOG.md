# Changelog

- 2026-07-12 — v1.0.0: ported obsidian-markdown into craft-skills → Obsidian Flavored Markdown syntax reference plus a compact note house style (heading/indent/spacing/footnote rules); genericized personal-vault framing and dropped the vault-specific fleeting-note reference. Provenance: bstack obsidian-tools/obsidian-markdown.
- 2026-07-26 — v2.0.0: operator house-style corrections from a vault note-cleanup session → **breaking**: Rule 6 reverses the web-link default from markdown footnotes to inline `[label](url)`, so a caller already formatting notes against v1.x gets different output for the same source and the `web links as footnotes` phrase leaves the description. Adds Rule 7 (body dates as `[[YYYY-MM-DD]]`, YAML date scalars stay plain, and no inferring a year the source never stated) and Rule 8 (person names as `[[Name]]` on first mention, People-note creation explicitly out of scope). Rule 2 now prefers nested tab bullets when an item has genuine sub-context and states that co-attributes of one subject are siblings, not children; it also absorbs the YAML-spaces carve-out that had been stranded under the web-link rule. Verification exempts date and person wikilinks from the resolve-or-placeholder check, since both are placeholders by design. Examples use neutral placeholders only. Provenance: operator correction during a note-formatting session.
