## Verified command surfaces

`qmd --help` at 2.5.3 confirms `qmd update`, `qmd update --pull`, `qmd embed`, `qmd query`, `qmd skill install --global`, `qmd skills list`, `qmd skills get`, `qmd skills path`, `qmd mcp`, and `qmd bench`.
The installed help does not state the version in which any of those subcommands first appeared, so their introduction versions are unverified.
`aside --help` at 1.26.902.1732 confirms `exec`, `repl`, `mcp`, `account list`, `account use`, `--account`, and `--effort ultrabrowse`.
`aside --session` is unverified because it is not listed by the installed help; use the documented `aside session <subcommand>` surface instead.

## Preflight recipe

1. Run `command -v <tool>` and that tool's exact version probe before declaring it unavailable.
2. Do not run a mutating subcommand such as `--update` or `install` as a probe.
3. Record `verified_against: <tool>@<version>` in the CHANGELOG bullet of every skill whose recipe depends on that tool.
4. Treat an unavailable, ambiguous, or unsupported tool as a boundary and report it rather than inventing a fallback.
